# Rajasthan CET 2026 Prep — Phase 1

React + Vite mobile-first foundation for a Rajasthan CET 2026 (12th Level) preparation platform.

## Phase 1 scope
- Vite + React + React Router architecture
- Mobile-first responsive shell
- Bottom navigation: Home / Practice / PYQ / Tests / Profile
- Dashboard foundation
- Subject cards foundation
- PYQ filter/mode foundation
- Test area foundation
- Central exam config (`src/config/examConfig.js`)
- Structured question-data placeholder (`src/data/questions.json`)
- Local-storage utility for future persistence

## Run
```bash
npm install
npm run dev
```

## Official-source note
Exam configuration is intentionally centralized and currently marked `official-details-to-be-verified`. Update it from the latest RSSB notification/syllabus before publishing exam-specific claims.

Question content in the demo JSON is placeholder content only. Import only legally usable/licensed/user-provided content.
